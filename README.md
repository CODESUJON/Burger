# Food Website

This project is a  interactive food-themed website that highlights various food categories with dynamic animations, videos, and scrolling effects.

## Features

- **Video Background:** A full-screen autoplay video providing an engaging visual experience.
- **Dynamic Text & Images:** Food categories like Veggies, Fish, Chicken, Lamb, and Blackbean displayed with animated headings and images.
- **Smooth Scrolling Effects:** Implemented using GSAP and Locomotive Scroll for smooth transitions and scroll-triggered animations.
- **Responsive Design:** Built using Tailwind CSS for responsive, mobile-friendly layouts.

## Technologies Used

- **HTML5**
- **CSS3** (TailwindCSS)
- **JavaScript**
  - [GSAP](https://cdnjs.com/libraries/gsap) for animations
  - [ScrollTrigger](https://cdnjs.com/libraries/gsap/3.12.5/ScrollTrigger) for scroll-based triggers
  - [Locomotive Scroll](https://cdn.jsdelivr.net/npm/locomotive-scroll@beta) for smooth scrolling
- **Font Awesome** for icons

## Troubleshooting

- **Video not showing:**
  - Ensure `1st.mp4` is in the `videos` folder.
  - Confirm the file path and file name are correct.
  - Test with a known working video link to verify if it's a file issue.
